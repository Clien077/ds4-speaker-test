DS4 / DualSense 手柄扬声器测试工具 —— 使用说明
=========================================================

【怎么启动】

  推荐：双击  DS4扬声器测试\DS4扬声器测试.exe        ← 文件夹版
        启动快（约 1 秒），运行时不解压任何文件，
        即使从聊天窗口的"文件卡片"打开也能正常跑。

  备用：双击  DS4扬声器测试(单文件).exe              ← 单文件版
        只有 52 MB、好搬运；但启动时要把自己解压到临时目录。
        如果你是从聊天窗口/沙箱环境打开的，可能报
        "Could not create temporary directory!"
        （低完整性进程不能往中完整性的 %TEMP% 写东西），
        这时改用上面的文件夹版，或在普通资源管理器窗口里双击。

  命令行：DS4扬声器测试-CLI.exe --bt --file 你的音乐.mp3
          DS4扬声器测试-CLI.exe --bt-list          （查看手柄 HID 接口）
          DS4扬声器测试-CLI.exe --bt-selftest      （离线自检，不发声）

【最简单的用法】

  1. 手柄用【蓝牙】连电脑（USB 直连时电脑只认 3.5mm 耳机口，内置喇叭测不了）
  2. 打开程序，"1. 输出通路与设备"应显示：
        蓝牙内置扬声器（HID + SBC，真正的喇叭）
        已找到：DualShock 4 v2 (CUH-ZCT2) · BT · 输出报告 547 字节
  3. 点"▶ 开始播放"，或点"♪ 完整测试序列"依次听全部测试音
  4. 想用自己的音频：选"自定义音频文件" → 浏览选择 wav / mp3 / flac / ogg / m4a …
  5. 不确定喇叭有没有响：点"开始回环自检"，它会用麦克风录回来自动判定

【没声音怎么办】

  · 先点"开始回环自检"——它会告诉你"完全没出声"还是"出声了但音量小"
  · 试换"报告通路字节"：0x02 = 内置扬声器（默认），0x24 = 3.5mm 耳机口
  · 手柄小喇叭音量本来就很小，请把手柄贴到耳边确认
  · 如果 DS4Windows 正在运行，先退出它（会抢占手柄的 HID 设备）
  · 插一副 3.5mm 耳机到手柄上对比：耳机有声、喇叭无声 = 喇叭本身的问题

【声音断断续续（蓝牙链路固有，已优化过）】

  · "预灌缓冲(条)"：6 → 12~20（垫厚手柄缓冲，代价是延迟略增）
  · "送流速率"：1.0 → 1.02（慢慢把缓冲垫厚；太高会溢出反而更卡）
  · "控制刷新(条)"：保持 20
  · 物理因素往往最有效：2.4G 无线鼠标接收器 / WiFi 与蓝牙同频，
    把接收器换个 USB 口或远离手柄、WiFi 切到 5GHz
