DS4 Speaker Test 1.1.0 - Quick start
Generated by DeepSeek-v4.1-Flash.  Full docs: README.md (English) / README.zh-CN.md (Chinese)

[ What this tool does ]
  Tests the DualShock 4 controller's audio. There are two completely different paths:

    1) HID + SBC  -> the controller's REAL INTERNAL SPEAKER
       Needs Bluetooth, or the official Sony USB wireless adapter (CUH-ZWA1).
       A plain USB cable CANNOT drive the internal speaker (hardware limit).

    2) Windows audio endpoint -> the 3.5 mm headphone jack only.
       Works over a USB cable or Bluetooth audio; plug headphones into the controller.

  Any custom test audio is supported (wav / mp3 / flac / ogg / m4a ...).

[ Run it ]
  GUI      : double-click DS4-Speaker-Test.exe  (folder build, recommended)
  CLI      : DS4-Speaker-Test-CLI.exe --help

[ Typical commands ]
  --bt --signal sweep              play a sweep to the internal speaker (Bluetooth)
  --bt --file mysong.mp3           play your own file to the internal speaker
  --bt-list                        list controller HID interfaces and capabilities
  --wired                          wired mode: diagnosis + lightbar/rumble check + 3.5 mm jack
  --wired-control-test             lightbar + rumble check only (USB 0x05 report)
  --loopback-test                  play and record, then judge automatically
  --lang en | --lang zh            UI language (also switchable in the GUI dropdown)
  --version                        print version

[ No sound? ]
  * Run the loopback self-test: it tells you "silent" vs "quiet".
  * Internal speaker: make sure the controller is on Bluetooth (or the official adapter),
    the path byte is 0x02, and --bt-volume is 255.
  * Controller speaker volume is genuinely low - hold it next to your ear.
  * Exit DS4Windows first: it grabs the HID interface exclusively.
  * Stuttering is a Bluetooth link issue: raise "pre-buffer" to 12-20, set rate 1.02,
    and move 2.4 GHz dongles / Wi-Fi away from the controller.

[ Folder build vs single file ]
  The folder build (DS4-Speaker-Test\DS4-Speaker-Test.exe) never unpacks anything at runtime,
  so it starts from any location. The single-file EXE unpacks to its own directory on launch:
  start it from a normal Explorer window.
